# Local Studio preview bridge

The M1 Studio reads projects, sessions, pages and source models through the authenticated web-to-runner broker. It never writes source from a frame message. The runner supplies the trusted Astro integration only to a managed development worker, with an explicit local app origin. The integration injects a browser script only when Astro's command is `dev`; ordinary Astro commands and direct fixture builds do not include it.

On each iframe load the frame sends a route-only hello to the exact app origin. The Studio matches the sender to the active iframe window and the origin to the session's `localhost` preview URL, then loads the current server source model. It initializes the frame with project, session, preview generation, frame ID, page, revision and an anchor-to-source-key map. Those keys are revision-scoped model target IDs. A new frame, page, generation or source revision invalidates the old selection immediately.

The script adds runtime `data-stellar-*` markers to exact DOM IDs identified by the model. It never changes project source files or Astro config. Selection reports geometry, a DOM occurrence ID, an exact anchor/source key pair and display-only computed styles. The Studio validates the full envelope against the expected origin, iframe window and current scope, and resolves the pair only against its server-fetched model. A duplicate DOM anchor, missing element or unmarked descendant is diagnostic/read-only. Repeated component targets remain read-only according to the source model. A ready message and geometry update cannot authorize a write.

The frame draws hover and selection outlines as fixed, pointer-ignoring overlays inside its own viewport. Scrolling and resizing recompute geometry. The iframe's CSS layout width changes with the selected viewport; fit scaling transforms the complete frame afterward, preserving its media-query behavior and overlay alignment. Inspect mode intercepts page clicks and submits. Interact mode leaves site navigation active and the route-only handshake reconciles the selected page after navigation.
