# User Guide

Write one guide per shipped, user-facing feature for the audience in `documentation.userGuideAudience`. Copy `_template.md` and describe actions in plain language, using the labels visible in the application. Verify each step against the shipped interface. Update a guide when the behavior it describes changes. Keep unreleased or speculative flows out of user instructions; record open questions in the relevant PRD or ExecPlan.
