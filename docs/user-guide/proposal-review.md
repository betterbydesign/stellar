# Reviewing proposed changes

Account project pages include a proposal review area. With the current disconnected foundation, real projects have no generated proposals. Provider generation and source application are unavailable.

When an authorized proposal record exists, open it to inspect the exact command, source revision, proposed change and expiry. Editors can record an approval, reject a proposal or cancel it. Viewers can inspect records but cannot decide. An approval records review intent only: it does not change the website or authorize a later source write. Rejecting and cancelling also leave source untouched.

If a review request loses its response, retain the original request and reload/reconcile before starting another decision. Current grants are checked again on every request. Changed, expired or stale review content cannot be approved. Connecting source and enabling application require the separate live acceptance gates.

The development proposal harness is explicitly synthetic. Its examples and browser persistence are isolated from account projects and do not demonstrate live identity, database persistence or a provider job.
